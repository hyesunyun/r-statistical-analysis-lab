# r-statistical-analysis-lab

Lab for CS6983/CS4973 Research in Human-Centered NLP (Northeastern University).

We will use **R** to conduct some statistical analysis from data gathered for evaluation.

The **R** programming language is a dynamic language built for statistical computing and graphics. 
R is commonly used in statistical analysis, scientific computing, machine learning, and data visualization.
It compiles and runs on a wide variety of UNIX platforms, Windows and MacOS.

## Google Colab

You can run the notebook on Google Colab. This would be the easiest option to work with R without having to download packages and dependencies ahead of time.

In order to run R in Colab, set the right runtime.

## Running Locally

You can also run `.R` files locally on [RStudio](https://posit.co/products/open-source/rstudio/) or [Visual Studio Code](https://code.visualstudio.com/).

1. Download `R` if you haven't done it already following the instructions found here: https://www.r-project.org/
2. Download either RStudio or Visual Studio Code (VSCode), depending on which IDE you would like to use.

### RStudio
**RStudio** is a very popular IDE for R. 
It includes a console, syntax-highlighting editor that supports direct code execution, and tools for plotting, history, debugging, and workspace management. 
RStudio is available as open source and runs on the desktop (Windows, Mac, and Linux). 

Follow the instructions on downloading R and RStudio Desktop

**Instructions**:
https://posit.co/download/rstudio-desktop/

### VSCode

The [R extension](https://marketplace.visualstudio.com/items?itemName=REditorSupport.r) for VSCode supports extended syntax highlighting, code completion, linting, formatting, interacting with R terminals, viewing data, plots, workspace variables, help pages, managing packages and working with [R Markdown](https://github.com/REditorSupport/vscode-R/wiki/R-Markdown) documents.

Follow the `Getting Started` instructions to run `R` files or code in VSCode.

**Instructions**:
https://code.visualstudio.com/docs/languages/r
